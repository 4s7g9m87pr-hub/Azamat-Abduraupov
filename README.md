## Как открыть

Откройте `index.html` двойным щелчком в Safari, Chrome или другом современном браузере. Все изображения находятся в `images/`, интернет для основной страницы не нужен.

Для просмотра через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Установка библиотек для самого сайта не требуется.

## Что реализовано

- Семантические `header`, `nav`, `main`, `section`, `article`, `footer`, `hgroup`; контейнеры `div` полностью исключены, включая разметку диалогов.
- Главное меню Cases, About me, Prices, Contacts; бургер на мобильном.
- Hero, иллюстрированный аватар, USP и кнопка View cases.
- Четыре оригинальных учебных кейса с превью, категориями и подробностями в диалоговых окнах.
- Блок About, навыки, этапы работы и три примера тарифов в тенге.
- Форма: имя, email, телефон, ссылка на ТЗ, тип услуги, описание и согласие.
- Валидация через HTML-атрибуты `required`, `minlength`, `maxlength`, `pattern` и правильные типы полей; подсветка ошибок через CSS `:user-invalid`.
- Светлая и тёмная темы; выбор темы сохраняется локально.
- Сетки из 12 колонок на компьютере и 4 на телефоне; одноколоночные карточки на узком экране.
- Полный universal reset, относительные единицы в `style.css`; обязательный `@media (min-width: 1024px)`.
- Скруглённые компоненты; squircle через `corner-shape` в поддерживающих браузерах.
- Клавиатурная навигация, заметный фокус, skip-link, aria-labels, reduced motion.
- Ссылки Behance и Dribbble, copyright, Privacy и Terms.
- SVG с текстом, переведённым в контуры, и WebP-экспорты.

## Честные ограничения учебного проекта

1. Фото пользователя не предоставлено. В hero стоит оригинальный иллюстрированный аватар. Для буквального выполнения пункта «personal photo» замените `images/portrait.svg` своим фото и измените `src` и `alt` изображения.
2. Кейсы и цены — явно обозначенные учебные примеры. Это не утверждения о реальных клиентах или действующих коммерческих предложениях.
3. Форма не отправляет заявки на сервер или email. Она сохраняет **один** бриф в браузере, позволяет скачать `.txt` и удалить запись. Новый бриф заменяет предыдущий. При недоступном localStorage доступна загрузка текущего брифа. Для реальных заявок нужен отдельный согласованный адрес/обработчик.
4. Ссылки Behance и Dribbble ведут на главные страницы платформ, поскольку личные профили не предоставлены.
5. HTML-макеты и SVG-экспорты не являются нативным `.fig`-файлом. Для выполнения проверки именно в Figma их нужно импортировать в аккаунт и создать/проверить frames и Layout Grids.

## Проверки и сборка

```bash
node scripts/check.mjs
node --check script.js
node scripts/build.mjs
```

Результат сборки — `dist/`. Файлы страницы также лежат в корне для GitHub Pages.

`scripts/generate-assets.py` — необязательный исходный генератор иллюстраций. Для повторной генерации нужны Python, FontTools, CairoSVG и Pillow. Готовые изображения уже включены.

## GitHub Pages

Публичный репозиторий: https://github.com/4s7g9m87pr-hub/Azamat-Abduraupov

Проект подходит для публикации из ветки `main`, папки `/ (root)`. В Settings → Pages выберите Deploy from a branch → main → / (root). Файл `.nojekyll` включён. Все локальные ссылки относительные, поэтому сайт работает в подпапке репозитория.

Для сдачи нужны два проверенных адреса: публичный репозиторий и работающий GitHub Pages. Приватный предпросмотр в ChatGPT не заменяет GitHub Pages.

## Figma

Полные четыре SVG и WebP-макета включены в архив сдачи. В репозитории находится интерактивная версия `design/frames.html`.

Откройте `design/frames.html` для просмотра. Импортируйте четыре SVG в Figma и оберните каждый в Frame соответствующей ширины. Добавьте Layout Grid: 12 колонок для 1440, 4 для 390; margins и gaps указаны в `design/TOKENS.md`. SVG содержат графические элементы и текст в контурах. Скриншоты и HTML-iframe не заменяют нативные Figma frames.
